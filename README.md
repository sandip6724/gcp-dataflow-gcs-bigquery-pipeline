# GCP-dataflow-GCS-to-BQ
🚀 GCP Data Pipeline using Dataflow (Local → GCS → BigQuery)
📌 Project Overview

This project demonstrates a batch data pipeline built on Google Cloud Platform (GCP) using Apache Beam (Python SDK) and Dataflow.

The pipeline ingests data from a local machine, uploads it to Google Cloud Storage (GCS), and processes it using Dataflow before loading it into BigQuery for analytics.
